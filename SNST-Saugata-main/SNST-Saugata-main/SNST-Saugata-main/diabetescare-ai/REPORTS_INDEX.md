## 📋 Report Template Structure (Per Provided Format)

Each weekly report for each person includes:

### **Section A: Work Completed This Week (4-5 bullets)**
✅ Specific technical deliverables with metrics and line counts
- Example: "Built X with Y% accuracy, tested on Z samples"
- Includes: Features built, tests run, performance metrics

### **Section B: Code and Files Submitted (Exact Links)**
✅ GitHub links with line counts and documentation
- Example: "GitHub: Feature - path/to/file.py (N lines)"
- Includes: Code files, test results, documentation links

### **Section C: Problems Faced (Specific Issues)**
✅ What broke, what was tried, solutions implemented
- Example: "Issue: X problem occurred. Solution: Fixed by doing Y"
- Includes: Blockers, obstacles, troubleshooting steps

### **Section D: Help Needed from PI**
✅ Blockers or dependencies
- Example: "No blockers - Week complete" or "Need resource X by date Y"

### **Section E: Targets for Next Week (3-4 Measurable Goals)**
✅ Specific numbered goals with metrics
- Example: "Complete X with ≥Y% accuracy by date Z"

### **Self-Assessment**
✅ Circle one: On track / Slightly behind / Need urgent help
