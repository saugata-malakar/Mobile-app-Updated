ANALYSIS
================================================================================

WHY FL OUTPERFORMED CENTRALIZED:
1. Data Augmentation: Each client applies different augmentations
2. Ensemble Effect: FedAvg combines knowledge from 3 models
3. Regularization: Local training prevents overfitting
4. More Training Steps: 5 rounds x 2 epochs = 10 total epochs

PRIVACY BENEFITS:
- No raw patient images leave any client node
- Only model weight updates are shared
- Differential privacy can be added for stronger guarantees
- GDPR-compliant data processing

FEDAVG ALGORITHM:
1. Server sends global model to all clients
2. Each client trains locally for 2 epochs
3. Clients send model updates to server
4. Server aggregates updates with weighted averaging
5. Repeat for 5 rounds
